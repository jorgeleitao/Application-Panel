# Painel de Candidaturas (local)

1. Tenha o Node.js instalado (qualquer versão recente).
2. Na pasta, rode: `node server.js`
3. Abra http://localhost:3000

Seus dados ficam em `data.json` (e a versão anterior em `data.json.bak`), na própria pasta.
Para fazer backup, copie essa pasta. Porta diferente: `PORT=4000 node server.js`.
O servidor só aceita conexões da sua própria máquina.
